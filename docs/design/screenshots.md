# Design: screenshots for the v1.0.0 release

This directory holds screenshots and mockups as the UI evolves
(SPEC §15). **The M9 slots below are placeholders** — they will be
filled with real captures during the release pass (nothing here is
fabricated; the app must be screenshot, not imagined).

Capture every shot in **both light and dark** appearance, at 2× scale,
with the Paper theme unless noted. Save as `docs/design/<name>.png`
and embed it in the README table below.
