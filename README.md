# Arbor

A free, native macOS mind-mapping app for thinking, presenting and learning. It does everything MindNode Plus does, adds presentation and spaced-repetition study modes, stores maps as real files, and has no subscription.

## Highlights (planned)
- **Editing:** keyboard-first, with animated auto-layout. Structures include mind map, org chart, logic chart, radial, timeline and fishbone, and you can mix them per branch.
- **Node content:** notes in Markdown, images, SF Symbols and stickers, LaTeX, code, tasks with progress rings, tags, connections, boundaries and summaries.
- **Views:** an outline view, side by side with the map. Focus and Zen modes, Quick Entry from the menu bar, and a command palette.
- **Look:** 12 dynamic themes plus a real theme editor.
- **Present:** auto or authored slides, branch-by-branch builds, and a presenter view on a second display.
- **Study:** FSRS flashcards straight from your branches, a recall mode on the canvas, and a mastery heatmap.
- **AI:** on-device Apple Intelligence, or bring your own API key. Off by default.
- **Import and export:** OPML, Markdown, FreeMind, XMind, MindNode, PDF, PNG, SVG and more.
- **System integration:** Spotlight, Quick Look, Shortcuts, Reminders sync and a local MCP server.

## Requirements
macOS 26 or later. Built with Xcode 27 and Swift 6.4.
